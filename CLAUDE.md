## Agent skills

### Issue tracker

Issues live in GitHub Issues (`gh` CLI); external PRs are not a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Default label vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout (`CONTEXT.md` + `docs/adr/` at the repo root). See `docs/agents/domain.md`.

### Frontend init

Before writing any cat-care frontend code, read the wayfinder map (GitHub issue #1) and its closed child tickets' resolution comments — see `docs/agents/init-frontend.md` for the index and the multi-sub-agent build workflow.
